#### Projects I assist in maintaining or authored:
- [`2140-dev/kyoto`](https://github.com/2140-dev/kyoto): Private Bitcoin light client, available for use with [Bitcoin Dev Kit](https://github.com/bitcoindevkit/bdk-ffi) in Rust, Swift, Python, and Kotlin
- [`kernel-node/kernel-node`](https://github.com/kernel-node/kernel-node): Bitcoin full node written in Rust with [`libbitcoinkernel`](https://github.com/bitcoin/bitcoin/blob/master/doc/design/libraries.md)
- [`bitcoindevkit/bdk-kyoto`](https://github.com/bitcoindevkit/bdk-kyoto): Bitcoin Dev Kit and Kyoto integration that makes syncing wallets easy
- [`rust-bitcoin/chacha20_poly1305`](https://github.com/rust-bitcoin/rust-bitcoin): ChaCha20Poly1305 implementation, optimized on `x86` and `aarch64`
- [`rust-bitcoin/bip324`](https://git.rust-bitcoin.org/rust-bitcoin/bip324/src/branch/main): Encrypted messaging for Bitcoin P2P messages, used by [Floresta](https://github.com/getfloresta/Floresta), [`rbitcoin`](https://github.com/rbitcoin-org/rbitcoin), and Kyoto
- [`rust-bitcoin/p2p`](https://github.com/rust-bitcoin/rust-bitcoin): (De)serialization of Bitcoin P2P messages as Rust types
- [`2140-dev/bitcoin-capnp-types`](https://github.com/2140-dev/bitcoin-capnp-types): Rust and Bitcoin Core IPC bridge, used in [Stratum mining protocol](https://github.com/stratum-mining/stratum/tree/main)
- [`2140-dev/hintsfile`](https://github.com/2140-dev/hintsfile): UTXO hints for the [SwiftSync protocol](https://gist.github.com/RubenSomsen/a61a37d14182ccd78760e477c78133cd), used by [Floresta](https://github.com/getfloresta/Floresta)
